Source: decision of the coordinating session on ^5xy53sw, group 4 (a).

Router has no close(), so a test that makes only a Router has no session to close. That part of rule T1 is out of scope. But a Router-only test that makes a temporary directory must also remove it when the test body throws.

- [ ] Find each test that makes a Router (and no session) and makes a temporary directory.
- [ ] Make each one remove the directory also on a throw. Use the shared helper `RouterTestFixtures.removingDirectoryOnThrow` (or `defer`), not a new local copy.
- [ ] Run the full suite one time.

Work in one agent, with no parallel agents on the working tree. Edit files only with the edit tool. Do not run swift format. No .timeLimit, sleep, poll or retry.
