title: Stop the generation on a no-op tool call while an operation is pending
---
## Problem

Evidence: bench run no-otel-1011 (2026-10-11), django__django-13964. A runCode call went pending. Then the model made 73 no-op runCode calls (`return "waiting placeholder"`, `return null`, `return "end 11"`, `"done 12"`, ...) from seq 2027 to seq 2319. Its reasoning said "I'm stuck in a loop ... I'll end my turn with text only". The next output had a tool call again. Only the repetition watch stopped it (seq 2323-2325: watchStop finish=repeatedLines, recovery=1). The same loop occurred before (Multitool task ^cf57dtd: 133 x `return "waitingN"`).

## Decision of the user

- There are no turns. There are only async queues.
- The session injects the result of pending work as a new message. That message starts the model again.
- Parallel tool calls must stay free.
- If there is no other work, the model must do nothing.

## Task

1. While at least one operation of the session is pending, a no-op tool call stops the generation.
2. For a no-op tool call, the session does not run the call, does not answer it, and does not put it in the context.
3. The session then waits. The injected result is the next thing that the model sees.
4. A real tool call always runs, also while other work is pending.
5. Do not use the repetition watch for this behavior.

## Coordination

- The Multitool session (foundationmodelsmultitool-a4) has a task to mark a runCode call whose snippet calls no `tools.*` verb. Agree the form of that mark with that session before you implement step 1.
- Multitool changes its pending text to: "... the session injects its result into this conversation as a new message. That message starts you working again ... If no other work can be done until the result comes back, do nothing: write no text and call no tool."

## Acceptance

- A test: one operation is pending, the model makes a no-op tool call. The generation stops. The call is not in the context. The injected result is the next message.
- A test: one operation is pending, the model makes a real tool call. The call runs.
- A test: no operation is pending, the model makes a no-op tool call. The behavior does not change.
