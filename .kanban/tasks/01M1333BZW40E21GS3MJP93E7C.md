## What

`JSONValue` is public, but the only method that returns it — the guided `respond(to:matching:)` in Sources/FoundationModelsRouter/Guided/GuidedGeneration.swift:210 — is internal. The audit reads this as an unfinished feature: the overload was meant to be public. Publish it.

- Make `respond(to:matching:)` public. Its doc comment at lines 200-210 is already complete, with `- Parameters:`, `- Returns:`, and `- Throws:`; leave it as it is.
- Publish `GuidedRequestError` (Sources/FoundationModelsRouter/Guided/GuidedGeneration.swift:7), which is internal today. It is the error the method documents throwing. Without it a plain-import consumer cannot name or catch the failure, and the ``GuidedRequestError`` doc link becomes the same unresolvable-internal-symbol defect the DocC repair task is fixing.
- `JSONValue`'s members are already sufficient: the six cases plus `Codable` and `Equatable` are public (Core/JSONValue.swift:5, GuidedGeneration.swift:187). Add nothing to it.
- Create a new DocC page `Sources/FoundationModelsRouter/FoundationModelsRouter.docc/GuidedGeneration.md` for this surface. The catalog holds only `RoutedSession.md` today, so this is a new file and does not collide with the other tasks that edit the catalog.
