## Why

FoundationModelsMultitool, AgentViewKit, FoundationModelsExtras and FoundationModelsAgents use the Router from its `main` branch. The work-queue tasks (^a0ze9af, ^1psqdm9, ^dpn2ytt, ^3qx0mpt, ^cbhpdjy, ^x7cxsg3, ^5d0qx1b, ^f33q8gw) break their build and change their behavior. The user decided on 2026-09-24 that breaking the consumers is acceptable, because they are our own packages. Design: `generation-queue.md`, section 5.10, which lists what each consumer must change.

## What to do

1. Before you edit a consumer, read its board. If its board says that it adopts the change itself, do not edit it: write that in a comment here.
2. Do NOT edit `../FoundationModelsACPAgent` (user decision 2026-09-24). Write the final list of old name to new name in a comment here and on the ACP card ^tz867gz (ACP board), and name the behavior changes that reach it: `awaitingUser` is gone (10 uses there), and a permission wait in an in-band tool now holds the model for every session on it; `passQueued`/`passStarted` (card ^rfn4m87) are now `submissionQueued`/`submissionStarted`; `turnEnded` (26 uses) is now `submissionEnded`, and the end of an answer is `answered`.
3. `../FoundationModelsMultitool`: `TurnBoundaryTool`/`turnWillBegin()` (27 uses) become `SubmissionBoundaryTool`/`submissionWillBegin()`; `turnEnded`/`turnStarted` become the submission events; `cancelCurrentTurn()` becomes `cancel()`; remove the `dispatchNextPrompt()` driver.
4. `../AgentViewKit`: `cancelCurrentTurn()` (11), `turnEnded` (10), `turnStarted` (6), `TurnStart`, `TurnID` become `cancel()`, the submission and answer events, `SubmissionStart`, `SubmissionID`. A view that shows "the turn in flight" shows `SessionProjection.currentSubmission` and the waiting messages.
5. `../FoundationModelsExtras`: `TurnOutcome` becomes `SessionAnswer`.
6. `../FoundationModelsAgents`: remove the `dispatchNextPrompt()` driver (12 uses; the pump delivers each message and each settled run); `cancelCurrentTurn()` becomes `cancel()`; the agent tool must start a child run as a background run and return at once (an in-band wait for a child on the same model gets `GenerationQueueError.waitInsideOpenSubmission`). Review the text "Its final message comes to you when it finishes." (`AgentsToolText`) and the "turn" words of `AgentRun+TurnLimit` and `AgentRunProgress`: the model must still end its submission to receive mail, because mail goes in only between submissions.
7. Build and test each edited consumer against the Router working tree.
