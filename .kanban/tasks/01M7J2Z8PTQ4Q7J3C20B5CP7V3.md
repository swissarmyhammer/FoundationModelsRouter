## What
When the model gives only no-op tool calls and NO background work is pending, the router now ends the answer with the last text of the model. When the model wrote no text, the answer has no text. A user asked "what is today", got a tool call, and then no answer. ACPAgent a9c0639 fixed its side.

The router must ask the model for the answer text (one more pass with no tool call), not end the answer with no text.

## Acceptance criteria
- [ ] A round of only no-op calls with nothing pending and no text from the model gives a final answer with the text of a next model pass.
- [ ] A round of only no-op calls with text from the model still ends the answer with that text (the current behavior of `NoOpToolCallWithNothingPendingTests`), or the new behavior is the same for both. Decide and document.
- [ ] Regression test in `Tests/FoundationModelsRouterTests/NoOpToolCallWithNothingPendingTests.swift`.
