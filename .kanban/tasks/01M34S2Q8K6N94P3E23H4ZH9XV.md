## Decision (from the owner, 2026-09-22)

`ToolContext.deadlineSecondsCeiling` (86,400 s, `Hosting/ToolContext.swift:18`) is an invented bound and must go. A caller's deadline is honored as given. No deadline means the wait ends at settlement or at cancellation.

## Why

- Born as `waitSecondsCeiling` in 8e9566f (2026-08-04), renamed in 0c32e22. No reason for one day.
- Today a background run longer than a day ends the turn-end drain early with `deadlineElapsed`, and a caller that asks to wait longer gets less, with no report.
- The one real reason for a guard is arithmetic: `Task.sleep(nanoseconds:)` takes `UInt64`, and `UInt64(Double.infinity * 1e9)` traps. That guard stays; it is a fact about the type.

## Sites

- `Hosting/ToolContext.swift:16-18`: the constant. `:229-234`: docs.
- `Hosting/SessionMailbox.swift:414-420` `boundedNanoseconds(clamping:)`: the clamp. `:186-211` `wait(completionToken:seconds:)`: takes a `Double` deadline.
- `Session/RoutedSessionActorGeneration.swift:28, 90, 124`: the drain passes the ceiling as its wait.
- `Hosting/ToolRun.swift:174`: the timeout window. `Hosting/BackgroundToolRunner.swift:181`: the grace sleep.
- Tests that assert the clamp (search `deadlineSecondsCeiling` and `boundedNanoseconds` in `Tests/`).

## Do this

1. Delete the constant.
2. `boundedNanoseconds` keeps only the arithmetic guard: NaN and negative give 0; a value at or above `Double(UInt64.max) / nanosecondsPerSecond` gives `UInt64.max`; everything else converts as is.
3. `wait(completionToken:seconds:)` takes `seconds: Double?`. `nil` registers no expiry task; the waiter resumes at settlement, or when the caller's task is cancelled. Keep the `Double` path for a caller that names a deadline.
4. The turn-end drain (`awaitSettlement`) passes `nil`. Its exits are settlement and cancellation, which it already handles. Remove the `deadlineElapsed` branch from `settleBackgroundRuns` if nothing can produce it there. Update the docs at `:28` and `:90`.
5. `ToolRun` and `BackgroundToolRunner` keep their own values (a per-call timeout is a host-stated number) and pass them through the guard as is.
6. Rewrite the docs that mention the ceiling.

## Acceptance

- `rg 'deadlineSecondsCeiling'` finds nothing.
- A `wait` with `seconds: nil` on a run that settles after 2 s returns `.settled`. A `wait` with `seconds: 1` on the same run returns `.deadlineElapsed`.
- `boundedNanoseconds(clamping: .infinity) == UInt64.max`; `boundedNanoseconds(clamping: 90_000) == 90_000 * 1e9`.
- All tests pass. #compaction #limits
