## What
User decision (2026-10-22, relayed by ACPAgent): the project registry must live where the host says, so TestudoApp can keep it in its iCloud app folder. It is not a JSONL file. It is a folder with one file per project, so concurrent writes from several devices through iCloud cannot conflict.

- `ProjectStore(directory:)` replaces `ProjectRegistry` and `projects.jsonl`. The host gives the folder, and Router never picks a default location.
- One file per project is named `<sha256 of the standardized project path, hex>.md`. It is markdown with frontmatter that holds the path and the record fields, and it is written with the Extras FrontmatterDocument save (temp file, then swap).
- Removing a project deletes its file. Updating a project rewrites only its own file.
- Listing reads every `.md` in the folder and skips files it cannot decode, with a warning.
- No backward compatibility: delete ProjectRegistry, ProjectRegistryRecord and projects.jsonl.
