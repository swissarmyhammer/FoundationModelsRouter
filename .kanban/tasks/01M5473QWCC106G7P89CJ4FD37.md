    - Production `awaitIdle()` (RoutedSessionActorIdle.swift, `isIdle()`) counts a staged terminal of a settled run as work (`SessionOutbox.canStartASubmission`). The funnel of a real background tool stages the terminal before the run plane settles the run, so the end of `awaitIdle()` comes after the delivery prompt in each run. The test helper `becomesIdle()` does not see a staged terminal: between the settle and the wake of the pump it can say idle. So the delivery waits (InlineSettleGraceSessionTests, SessionMailQueueTests settled-run delivery, RespondRunPlaneDrainTests `deliveryPrompt` and the two-run delivery) end on the end of `awaitIdle()`, not on `becomesIdle()`.
