title: 'Host API: begin background work on a routed session outside a tool call'
---
## What
FoundationModelsACPAgent asked for this (user-approved). On a resume, ACPAgent restores a session's scheduled agents with FoundationModelsAgents `AgentRunner.restoreSchedules(of:workSite:)`. Here `AgentScheduleWorkSite = @Sendable (String) -> BackgroundWork` opens the `childSession` lease of each firing in the work registry of the owner session.

ACPAgent can't reach that registry today:
- `RoutedSessionActor.workRegistry` is internal (Session/RoutedSessionActor.swift:399).
- `ToolContext.beginBackgroundWork` exists only inside a tool call.

So ACPAgent passes nil, and a restored firing holds no lease. While only a restored scheduled agent runs:
- the session shows no work,
- a headless run can exit,
- the idle `_meta.noWork` can fire early.

## Design
Add a nonisolated, synchronous requirement to `RoutedSession` (Session/RoutedSession.swift:46). It is synchronous so a `@Sendable (String) -> BackgroundWork` closure can call it:

```swift
nonisolated func beginBackgroundWork(_ kind: WorkKind, id: String) -> BackgroundWork
```

`RoutedSessionActor` implements it with the existing `beginWork(_:id:)` (Session/RoutedSessionActorWorkEvents.swift:394). That call already:
- counts the begin, so a racing work-end check sends no `workEnded`,
- begins the lease in `workRegistry`,
- sends `workStarted` when it is due.

A host lease therefore counts in the no-work state and the idle notice exactly as a tool's lease does.

Doc it with an example: a scheduled firing passes `.childSession` (the kind `AgentScheduleWorkSite` documents), with something like `workSite: { session.beginBackgroundWork(.childSession, id: $0) }`. After `close()` starts, the registry is closed; document what a begin does then. Read `WorkRegistry.begin` in Extras and state its actual behavior.

This is a breaking change for conformers: ACPAgent's test conformer `CloseCountingRoutedSession` must add it. It's pre-ship, so there's no default implementation.

  - After `lease.end()`, `workEnded` comes and the idle wait finishes.
