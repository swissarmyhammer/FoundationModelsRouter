## Goal

A live fork (^3hxcxee) reuses the KV cache of its source for the history that they share, so the first prompt of the fork does not compute the prefix again. Decision D205 (f). Brief: `../.briefs/fork/router-brief.md`, item 8. Optional: no other package waits for this task. Do it after all required D204 and D205 tasks.

## Change

- Find how the backend keeps the KV cache of a session (`Session/LanguageModelSessionBackend.swift`, `Resolution/LiveModelLoader.swift`, the MLX and llama.cpp paths) and if `makeFork()` can share or copy the cache up to the cut.
- If the backend can do it: use the cache of the source up to the cut when the fork is made. The source and the fork must stay independent after the cut.
- If the backend cannot do it: write down why on this task, and close it with no code change.
