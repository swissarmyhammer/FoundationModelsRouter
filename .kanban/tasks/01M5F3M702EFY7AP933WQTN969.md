## Goal
A pure, fully unit-tested resolver that turns the `to` of an `OutgoingSessionMessage` into a decision: which sessions get the message, whether a session must be started, or why the send is refused.

## Spec
- /Users/wballard/github/swissarmyhammer/TestudoApp/features/packages/foundationmodels-router.md#router-4-messages-between-sessions
- /Users/wballard/github/swissarmyhammer/FoundationModelsRouter/session.md section 5.6
- /Users/wballard/github/swissarmyhammer/FoundationModelsMultitool/session.md section 9 (the addressing table) and 13.3

## Why depends_on leaves out ROUTER-8
The spec puts ROUTER-4 after ROUTER-3 and ROUTER-8, because an agent address can start a session. This resolver is pure: it only returns `startAgent`, and the send card (which does depend on ROUTER-8) calls the launcher. So it needs only the summaries of the directory card.

## What
- New `/Users/wballard/github/swissarmyhammer/FoundationModelsRouter/Sources/FoundationModelsRouter/Directory/SessionAddressResolution.swift`: an internal function over the sender, the address, the live `SessionSummary` list, and a lookup for a recorded summary by id. It returns an internal enum, for example:
  - `.deliver([ULID])` (live targets),
  - `.restoreThenDeliver(ULID)` (a session id that is recorded and not live; ROUTER-5 does the restore),
  - `.startAgent(agentID: String, folder: URL?)` (no live root session of that agent),
  - `.refused(reason: String)`.
- Rules (section 9):
  - `.session(id)`: live gives that session; recorded and not live gives restore-then-deliver; archived gives refused with the reason "archived"; unknown gives refused with "unknown session".
  - `.agent(id, folder)`: the newest live root session of that agent in `folder`, else in the working folder of a `.session` sender; none gives `startAgent`. A `.user` sender has no folder: until the spec owner answers, `@agent` with no folder from a user matches the newest live root session of that agent in any folder, and gives `startAgent(folder: nil)` when there is none.
  - `.folder(url)`: the newest live root session with that working folder, of any agent (no subagent, no fork); none gives refused with the hint "Name an agent: @agent:/path." (D61).
  - `.tag(tag)`: each live session with the tag except the sender; none gives one refused. The directory never starts a session for a tag. The cap of 8 tag targets is ROUTER-5.
  - Folders compare after `resolvingSymlinksInPath()` and with no trailing `/` (share the helper of the query card).
