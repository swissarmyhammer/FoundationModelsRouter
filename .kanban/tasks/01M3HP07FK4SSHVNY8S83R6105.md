## What

`SessionConfiguration` (`Sources/FoundationModelsRouter/Session/SessionConfiguration.swift`) has three separate fields for compaction: `budget`, `compactionPrompt` and `toolOutputProtection`. Apple's `summarizeHistory(entryThreshold:model:instructions:summaryPostamble:)` keeps all its compaction settings in one call. Put the three fields into one value.

Design (decided):
- New file `Sources/FoundationModelsRouter/Compaction/CompactionSettings.swift`:
  ```swift
  public struct CompactionSettings: Sendable {
      public var budget: TokenBudget?            // nil = manual compaction only
      public var prompt: CompactionPrompt        // default .default
      public var toolOutputProtection: ToolOutputProtection?
      public init(budget: TokenBudget? = nil, prompt: CompactionPrompt = .default,
                  toolOutputProtection: ToolOutputProtection? = nil)
  }
  ```
- `SessionConfiguration`: replace `budget`, `compactionPrompt` and `toolOutputProtection` with `public var compaction: CompactionSettings`, and the three init parameters with `compaction: CompactionSettings = CompactionSettings()`.
- The sidecar format does not change: `Persistable` keeps its flat `budget` and `compactionPrompt` keys, and `persistable` reads them from `compaction`. Old and new sidecars decode the same.
- The flat convenience parameters `budget:`, `compactionPrompt:` and `toolOutputProtection:` of `RoutedModel.makeSession(instructions:...)` and `makeGuidedSession(grammar:...)` stay. They are the short form, and 42 test files use them. Each one builds a `CompactionSettings`.
- `restoreSessionTree(...toolOutputProtection:)` does not change.

Files:
- `Sources/FoundationModelsRouter/Compaction/CompactionSettings.swift` (new).
- `Sources/FoundationModelsRouter/Session/SessionConfiguration.swift`.
- `Sources/FoundationModelsRouter/RoutedLLM.swift` — `makeSession(configuration:)` reads `configuration.compaction`; the flat `makeSession(instructions:...)` builds `SessionConfiguration(compaction: CompactionSettings(...))`.
- `Sources/FoundationModelsRouter/Guided/GuidedGeneration.swift` — the same for `makeGuidedSession`.
- `Sources/FoundationModelsRouter/Session/RoutedSessionActor.swift` (line ~682) and `Sources/FoundationModelsRouter/Recording/SessionTreeRestoration.swift` (lines ~367, ~479–480) — read and write through `compaction`.
