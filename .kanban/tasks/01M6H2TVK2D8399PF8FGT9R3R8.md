## What
The Agents restore renders the body of a restored child with the recorded first prompt as $ARGUMENTS (a restored session IS that session). Today a host has no public way to read that prompt without a restore. (Coordinator request, 2026-11-03.)

Add `firstPrompt: String?` to the public `RecordedChild` (Sources/FoundationModelsRouter/Directory/RecordedChild.swift): the text of the FIRST user message of the recorded transcript of that child. It is `nil` when the transcript has no user message yet. If it is cheap, give any recorded session the same read, for example `RouterSessionDirectory.firstPrompt(of: ULID) throws -> String?`.

Rules:
- Read the recording only. Restore nothing. Read the transcript events up to the first `.prompt` partial and stop; do not load the whole transcript or the whole tree.
- Use the text of the user prompt as recorded. Not the mail records, not the instructions.
- A typed error for an unreadable transcript, as `runStatuses(of:)` has.
- Keep it small. No change to restore.

## Acceptance Criteria
- [ ] `RecordedChild.firstPrompt` holds the first user prompt of the child, byte for byte.
- [ ] A child with no prompt gives `nil`.
- [ ] A host can read it without a restore, and the folder bytes do not change.
- [ ] The read stops at the first prompt (a long transcript is not loaded whole).
