Source: task ^dbr1dqy (T1 audit, done). The audit left "tests that never close their session or router at all (about 60 suites)" out of scope. A new check on 2026-10-17 found 107 suites with tests that make a RoutedSession and never close it. `Router` has no `close()`; only `RoutedSession` does, so this group is about sessions only. This card has the generation queue, pool, residency and concurrency suites.

Rule T1: each wait in a test must also end on the failure event (run settle, session close, stream end), or the test must fail before it waits. A fixture closes also when the test body throws.
Exception rule: first use an event that already exists (the session closes, the run settles, the feed ends). A hook only in test helpers is permitted. Do not change production code only for a test hook. When a case needs such a change, bring it to the coordinating session (swissarmyhammer-96) before you change it. Do not use `.timeLimit`, sleep, poll or retry. Run the full suite one time.
Work rules: do the work in one agent. Do not run parallel agents on the tree. Edit files only with the edit tool. Do not run swift format.

How to close (use the forms that T1 added):
- Put `defer { await <session>.close() }` right after the session is made, for each session the test makes (root, fork, the second session over the same container). With semaphore or latch gates, open the gates in the `defer` before the close (see `SessionFixtureLifecycle.close(_:opening:)`, Helpers/SessionFixtureLifecycle.swift:83, and the `release(_:forEachOf:)` form in ForkConcurrencyTests). `close()` is idempotent; an AsyncSemaphore signal with no waiter only adds a permit.
- A residency test that checks a release or an eviction after the last handle drops: a close does not drop the handle, but check that a close before the check does not change the resident count. If it does, close after the check and keep the `defer` for the throw path.
- After a close, a test that waits on a feed now ends on the feed end. Check that no test now passes only because a wait ends early.
