## Decision (from the owner, 2026-09-22)

`retryTargetHalvingDivisor` (2) and `loweredRetryTarget(from:)` (`Session/RoutedSessionActorTurnExecution.swift:655-666`) are an invented amount and must go. After a context overflow, the retry compacts to the room the turn needs, computed from the turn, not to `target / 2`.

## Why

- The halving came with the first auto-compaction commit, with no reason for 2.
- A lower target is needed: after the proactive compaction the transcript is at or under `target`, so a retry at the same target changes nothing. But the amount is a computation, not a fraction: the overflow means transcript + prompt + generation do not fit the window, and all three sizes are known.

## Do this

1. Delete the constant and `loweredRetryTarget(from:)`.
2. In `recoverFailedAttempt` (`:447-460`), compute the retry's target in tokens: `contextTokens − promptTokens − responseTokenCeiling`, where `promptTokens` is the composed prompt's size (measure it with the session's tokenizer, or with the same estimate the compactor uses, and say which in the code) and `responseTokenCeiling` is the ceiling this turn gave the backend. Cap the result at `budget.targetTokens`, so the retry never compacts to less than the configured target asks for a normal compaction.
3. When the result is not positive (the prompt alone, plus the response room, does not fit the window), no compaction helps. Do not retry. Throw the original overflow error, as the failed retry does today.
4. Build the `TokenBudget` for the retry from that token count (`TokenBudget` takes fractions; derive the fraction from `limit`, or add a token-valued initializer). Keep `limit` and `trigger` as they are.
5. Record the computed target on the `.compaction` event and in the log line, so a reader sees what the retry aimed for and why.
6. Update the tests in `AutoCompactionTests` that assert the halved target. Add: an overflow with a 1,000-token prompt on a 10,000-token window with a 2,000-token ceiling compacts to 7,000 tokens (capped at target when target is lower); an overflow whose prompt is larger than the window retries nothing and throws.

## Not a number

The retry still happens one time. That is a count of attempts, not a size, and the owner has not asked to change it.
