## What
Repo: `/Users/wballard/github/swissarmyhammer/FoundationModelsExtras`.

Decision (2026-09-26): Extras owns one process-wide model pool, a work queue for each model and a mailbox for sessions. FoundationModelsRouter and FoundationModelsMetadataRegistry both use it. This task adds the new product and copies the queue primitives into it. The router keeps its own copies until the router tasks change it to use this product.

- Add a library product and target `ModelPool` in `Package.swift`, at `Sources/ModelPool/`. Put it on a separate target, the same as `Marketplace`. It depends only on Foundation, `Synchronization` and the ULID package that the package already has. It does not depend on MLX, and the core `FoundationModelsExtras` target does not depend on it.
- Copy these files from `/Users/wballard/github/swissarmyhammer/FoundationModelsRouter/Sources/FoundationModelsRouter/` and make the API that other packages need `public`:
  - `Core/ModelRef.swift` (`ModelRef`)
  - `Concurrency/AsyncSemaphore.swift`
  - `Concurrency/GenerationQueue.swift`, `Concurrency/GenerationWorker.swift`, `Concurrency/GenerationQueueError.swift`
  - `Session/GenerationReentry.swift` (`ModelCallMark`, `SubmissionTarget`). The queue reads this mark to find a submission that waits inside an open submission on the same queue.
  - `Concurrency/RaceGate.swift`, and `SerialAsyncChain.swift` or `CancellableWait.swift` if the files above use them.
- Make the `onQueued` overload of `GenerationQueue.submit` `public`, because the router calls it (`RoutedSessionActorAnswerExecution.swift:769`).
- Keep all doc comments and all comments that tell why a construct is necessary. Do not simplify the cancellation code.
- Record the decision in `plan.md` §5 (the dependency budget does not change) and add the router and the registry to §6 as users.
