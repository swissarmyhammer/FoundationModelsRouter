## What

FoundationModelsExtras main (a91911d, in the resolved 2c37a78) removes `dimension` from `PooledEmbedding` (BREAKING). The Router does not build with it now.

## Build errors

- `Sources/FoundationModelsRouter/Resolution/LiveModelLoader.swift`: `LoadedPooledEmbedding.dimension` reads `embedding.dimension`.
- `Sources/FoundationModelsRouter/Resolution/PooledEmbeddingContainer.swift`: `init(hold:)` reads `embedding.dimension`.
- `Sources/FoundationModelsRouter/RoutedEmbedder.swift`: the public `RoutedModel.dimension` reads `container.dimension` (`LoadedEmbeddingContainer` gets `dimension` only from `PooledEmbedding`).
- `Tests/FoundationModelsRouterTests/SlotPoolLoaderTests.swift` reads `dimension` of `any PooledEmbedding` and of `any LoadedEmbeddingContainer`.

Tests that assert a dimension: `SlotPoolLoaderTests`, `PoolEntryQueueTests`, `EmbedTracingTests` (`embedding.dimension` span attribute), `ProfileLifecycleTests`, `ExamplesTests`, `ExtrasPoolResolveTests`.

## Decide

Where the dimension of a `RoutedEmbedder` comes from now (for example the count of the first vector, a `dimension` requirement on `LoadedEmbeddingContainer`, or no public `dimension`), and what the `embedding.dimension` span attribute carries. Found while doing ^v270zf4. #embedding
