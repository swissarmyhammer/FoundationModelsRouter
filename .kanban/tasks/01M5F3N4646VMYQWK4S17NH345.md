`SessionDirectory.send` delivers a message to each resolved target as a `Mail`, keeps a `SessionMessage` record (sender, `inReplyTo`, chain depth, client id of a UI sender, read flag), sends `messageDelivered`, and `inbox(of:markRead:)` gives the unread messages.
