## Why

With no turn-long gate, three workarounds have no purpose: the `awaitingUser` release and re-acquire, `GenerationPermitLoan`, and `withGenerationLent`. A person wait holds nothing, and a nested generation goes into the queue while the outer turn is in its tool. Design: `generation-queue.md`, section 2.

## What to do

1. Delete `GenerationPermitLoan`, `borrowsGenerationPermit`, `currentPermitLoan`, and `withGenerationLent` (`Session/GenerationReentry.swift`). Remove the `withGenerationLent` calls in `RunToCompletionRunner`, `ContextBindingTool`, and `BackgroundToolRunner` (`Hosting/`), and the loan in `runCancellableModelCall` (`Session/RoutedSessionActorTurnExecution.swift`: the `GenerationPermitLoan(...)` construction, its `defer` that closes it, and the `GenerationPermitLoan.$current.withValue` binding in the model-call task).
2. Keep `SessionReentryError.sameSessionTurnInFlight` and `isInsideOwnTurnToolCall` (`refuseReentryOntoThisSession()` and `isInsideOwnTurnToolCall` in `Session/RoutedSessionActorTurnGating.swift`). Base them on a new light task-local "this session is in a model call", bound in the model-call task of `runCancellableModelCall`, in place of the loan. `turnLock` is held for the whole turn, so a same-session turn from a tool must still be refused with a clear error, never park.
3. Keep `awaitingUser(_:)` in the `RoutedSession` protocol as a pass-through (`body()` only) in this task; the rename task ^f33q8gw decides its name. Delete `humanWaitDepth`, `humanWaitLenderTurnId`, `beginHumanWait`, `endHumanWait`. The memory `routed-session-cancellation-invariants` names the `endHumanWait()` re-validation; that invariant goes away with the code. Update that memory in the same change.
4. Write the new contract in the doc comment of `awaitingUser(_:)` in `RoutedSession.swift`.

## Tests to change

`HumanWaitGateTests`, `NestedGenerationReentryTests`, and the other files that name the loan (`rg -l "GenerationPermitLoan|awaitingUser|withGenerationLent" Tests`).

## Acceptance Criteria

- [ ] The agents case: a parent session in a tool body starts a child turn on the same model (different session) and waits for it in that tool. The child completes, then the parent completes. With a timeout, so a regression fails and does not hang.
- [ ] A tool that asks its own session for a turn or a fork gets `sameSessionTurnInFlight`.
- [ ] A person wait inside `awaitingUser` holds no queue place: another session completes a turn during it.
- [ ] A background run (`BackgroundToolRunner`) that generates on the same model after its turn ended completes.
- [ ] No symbol named `GenerationPermitLoan` or `withGenerationLent` stays in `Sources/`. The full suite is green. #generation-queue
