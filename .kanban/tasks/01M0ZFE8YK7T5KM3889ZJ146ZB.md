The wait-window design is gone. A background tool returns a handle on EVERY call; nothing waits a short time and then decides. But eleven places still describe that removed mechanism as if it were live, and two of them are in shipped source that a user of this package reads.

This card was raised for two stale symbol names. A survey found the true size. The card is grown to match, because the work is the same work: stop describing a mechanism that does not exist.
